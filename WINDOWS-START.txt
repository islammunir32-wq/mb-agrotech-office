WINDOWS LOCAL TESTING — M. B. AGROTECH

This archive contains source code, not the cloud database or credentials.
Install Python 3.12 or newer from python.org if necessary.
Extract this archive, then open PowerShell in the extracted mb-agrotech-office folder.

Run these commands one at a time:

py --version
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_demo
Get-Content .\data\demo-accounts.txt
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000 --noreload --insecure

ONLY AFTER THE SERVER RUNS ON YOUR WINDOWS COMPUTER:
Open http://127.0.0.1:8000/ in your browser on that computer.
Keep PowerShell open while using the application. Ctrl+C stops the server.
No PowerShell activation command is needed; use the explicit Python paths above.

DEVELOPMENT ACCOUNTS
admin = administrator
field_a / field_b = field staff assigned to different fictional customers
delivery_a / delivery_b = delivery staff; an administrator must assign deliveries first
Each password is randomly generated by seed_demo and displayed by Get-Content above.
These accounts are for fictional local testing, not production.

TEST FLOW
Log in as field_a; submit an invoice for DEMO-A.
Log out and log in as admin; approve the invoice.
Open the customer ledger and select the invoice month.
Submit a collection as field_a; approve it as admin.
View the monthly statement and confirm the collection credits the balance.
As admin assign a delivery to delivery_a, then log in as delivery_a to test it.
Do not use real financial data or send WhatsApp messages during testing.
The initial October 2026 sample closing balance and November opening are BDT 11,500.

Tests:
.\.venv\Scripts\python.exe manage.py test
.\.venv\Scripts\python.exe scripts\concurrency-check.py
.\.venv\Scripts\python.exe scripts\backup-check.py

See README.md for limitations and backup guidance. Do not deploy to WordPress or PHP hosting.
